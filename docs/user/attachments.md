# Attachments

Paste, drop, or pick files in the composer to attach them to a message. A message holds up to
twelve attachments.

## Uploads

On servers that support direct uploads, images upload as soon as you add them. Each tile shows its
progress, and the send button becomes available once every upload finishes. A failed upload shows
a retry button, and retries on its own when the connection comes back. Removing an attachment
deletes its upload.

Offline sends still work: the message keeps its images inline and sends when the server reconnects.
